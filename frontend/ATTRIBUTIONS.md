# Dashboard component attributions

- `src/components/CountUp.tsx` is installed from the official [React Bits](https://reactbits.dev/) registry as `CountUp-TS-CSS` and is used only for restrained integer metric transitions.
- `src/components/SkiperThemeToggle.tsx` adapts the free [Skiper UI theme toggle](https://skiper-ui.com/v1/skiper4). The visible dashboard credit satisfies Skiper UI's free-component attribution requirement.

Both components are intentionally limited to useful state feedback; Mercury does not use animated backgrounds or decorative trading-terminal effects.
